使用前，先知道這些

所有工具都使用 WebAssembly 嗎？

不是。此集合包含 JavaScript、瀏覽器原生 API 與 WebAssembly 實作。品牌名稱不代表每個工具都使用 WASM。

可以完全離線使用嗎？

不保證。部分工具會從 CDN 載入套件；本站尚未提供完整離線快取。不要將本地運算等同於完全離線。

「待功能驗證」與「暫停使用」有什麼差別？

待驗證代表尚未逐項確認輸出正確性；暫停使用代表已發現未完成實作或資源缺漏，已停用輸入與下載。請以備份檔案測試可開啟的工具。
